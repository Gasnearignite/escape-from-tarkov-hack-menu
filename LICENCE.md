## 🧩 About

**Escape from Tarkov Menu** is a curated list of Escape from Tarkov open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, extraction timer
- **Quality-of-Life Helpers** — inventory catalog, config manager, overlay notes
- **Research Notes** — raid layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Loot Tracker — track valuables and quest items in real time
- Extraction Timer — countdown to extracts with alerts
- Map Overlay — interactive map with custom markers
- Quest Helper — objectives and item locations

### Wallhack
- Inventory Catalog — browse item stats and prices
- Preset Manager — save and load gear presets
- Config Profiles — switch settings quickly

### Aimbot
- Training Mode Notes — practice aim and movement offline
- Recoil Patterns — study recoil behavior in test mode
- Ballistics Calculator — drop and penetration notes
